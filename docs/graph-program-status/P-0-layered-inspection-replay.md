Status: **PARTIAL / tooling experiment**

The bounded receipt tooling is in
[`p0-layered-inspection-replay-20261112.md`](../evidence/p0-layered-inspection-replay-20261112.md)
and is generated by
`tools/scripts/p0_layered_replay_receipt.py`. It keeps the authored semantic,
resolved resource, prepared plan, event/control, and rendered-output layers
independent. The checked-in fixture remains evidence-only and does not add a
runtime/API seam; it composes the existing installed G3 host consumer and
spectral frame consumer when supplied.

The two consumer fixtures emit explicit protocol attestation tokens required by
the receipt tool (`pulp.graph.g3-resolved-identity-consumer.v1` and
`pulp.signal.spectral-frame-codec-consumer.v1`). This is evidence-only output
metadata; it does not change a runtime or public API contract. The focused P0
self-test guards both tokens and the existing five planted layer mutations.

The envelope has separate authored, resolved, plan, event, and output IDs,
canonical-byte digests, source/tool/SDK provenance, PCM format and quality
metadata, and explicit capacities, latency, fallback, stream, and epoch facts.
The consumer gate invokes each named binary at both 64- and 128-frame
partitions and requires a matching partition attestation. Five one-layer
mutations are attributed to and rejected at their corresponding layer, with
positive controls for every baseline layer. The gate remains
`NOT_QUALIFIED` when either installed binary is unavailable.
