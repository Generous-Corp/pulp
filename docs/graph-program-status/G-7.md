# G-7 control and event edge probes

Status: implementation slice in progress; bounded control and event probes are
implemented in the serial routed executor and exposed through the public host
diagnostics API, CLI, and MCP schema. This slice does not complete G-7.

The control probe records the mapped parameter value at block start and end,
including the public parameter id and edge identity. The event probe records a
source edge observation before destination copy: event count, first status and
offset, and source buffer drops. Destination delivery remains governed by the
existing bounded MIDI buffer and its incompleteness state.

The probe ring is fixed at 256 records, lock-free for one producer and one
consumer, and allocation-free when unattached. Attachments fail closed for
unprepared graphs, unknown ports, missing edges, unsupported kinds, parallel
routing, and retired topology. Reattachment resets the ring and sample clock.

Evidence for this slice must include the public C++ consumer, an installed SDK
consumer, CLI/MCP parity, positive control and event publication, and a planted
compiled mutation that fails when publication is removed. Release build gates
remain required before publication.

Remaining G-7 scope is preserved: callback deadline qualification, latency and
load measurement, paced-realtime behavior, parallel execution qualification,
long-run loss characterization, and host/provider coverage are not claimed by
these probes. No result here promotes a local offline render into a
latency/load or real-time qualification receipt.
