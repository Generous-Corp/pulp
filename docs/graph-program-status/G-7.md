Open:

- **Parallel-execution probes.** Every probe kind refuses parallel routing with
  `UnsupportedExecution`; probes publish only from the serial routed executor.
- **Paced/realtime qualification.** Callback deadline, paced realtime behavior,
  long-run loss characterization and host/provider coverage are not claimed.
- **Quiesce enforcement.** Attach/detach require quiesced processing
  (`process()` and retained-snapshot rendering stopped); live attach is
  unsupported. Nothing enforces it: attach/detach replace the probe on the live
  snapshot, which the callback reads without the mutation lock. The snapshot
  slot's reader count is private, and checking it before mutating would still
  race a callback that pins right after the check, so the guarantee stays a
  caller contract until a real in-flight gate exists.
- **CLI/MCP control positive path.** The CLI/MCP accept the control schema but
  always refuse `MissingEdge`, because CLI-loaded graphs admit only built-in
  input/output/gain/MIDI nodes and cannot contain automation edges. Control
  probes are C++ API only. The CLI event path seeds one fixed note-on.
- **Agent ergonomics (§2.3).** An agent-authoring trial of the probe workflow
  and a probe terminology lint remain open. Refusal messages now name the cause
  and the fix for each `EdgeProbeStatus`.

The planted control/event runs in `examples/graph-control-event-probe` are
refusal-message controls: they skip processing and must stop with the exact
`rule=control-publication` / `rule=event-publication` message. They replace the
earlier `WILL_FAIL` registration recorded in the historical receipt below and
are not CI mutation coverage.

## Slice record (historical)

Status: implementation slice in progress; bounded control and event probes are
implemented in the serial routed executor and exposed through the public host
diagnostics API, CLI, and MCP schema. This slice does not complete G-7.

The control probe records the selected edge's per-edge mapped and slewed
parameter contribution at block start and end, before destination mixing and
bounds clamping, including the public parameter id and edge identity. The event
probe records a source edge observation before destination copy: event count,
first status and offset, and source buffer drops. Destination delivery remains
governed by the existing bounded MIDI buffer and its incompleteness state.

The probe ring is fixed at 256 records, lock-free for one producer and one
consumer, and allocation-free when unattached. Attachments fail closed for
unprepared graphs, unknown ports, missing edges, unsupported kinds, parallel
routing, and retired topology. Reattachment resets the ring and sample clock.

Evidence for this slice must include the public C++ consumer, an installed SDK
consumer, CLI/MCP parity, positive control and event publication, and a planted
compiled mutation that fails when publication is removed. Release build gates
remain required before publication.
