# G-10 — offline canonical spectral frame codec

Status: **PARTIAL**. The admitted offline P1–P3 codec and relevant R1/R3
metadata are implemented. The bounded routed R4 frame contract is now wired
through the spectral ports, with runtime validation and partition controls;
runtime modulation, granular fields, and A3 completion remain unqualified.

Authority: [admission at planning commit 60da3f180ff67d99bdad954cafc2704c1ef56ea4](https://github.com/danielraffel/pulp-planning/blob/60da3f180ff67d99bdad954cafc2704c1ef56ea4/graph-program-status/G-10.md)
and [reviewed contract c01851d28b7369ae1a1a9549d81a9dc1bee7a7b8](https://github.com/danielraffel/pulp-planning/blob/c01851d28b7369ae1a1a9549d81a9dc1bee7a7b8/graph-program-status/g10-contract-resolution-20261103.md).

The public owned-value API validates complete canonical streams, preserves finite
binary32 components, normalizes encoded zero signs, rejects noncanonical decode,
and checks geometry, chronology, byte/count caps and memory budgets before
allocation. Content identity uses SHA-256 of the canonical bytes. The reference
documents the wire format and the separately required synthesis drain policy.

The two golden hex files are copied unchanged from the reviewed contract commit.
The test constructs the asymmetric value independently and checks all encoded
bytes, both frozen SHA-256 identities, all decoded components, malformed input,
truncation, chronology, finite extremes/subnormals and budget boundaries. The
standalone CMake consumer now configures through the installed `Pulp::signal`
target and uses no source-tree include path. The install-prefix smoke builds and
runs that consumer, including its exact roundtrip and a CTest `WILL_FAIL`
unknown-profile mutation, so a package that stops rejecting that malformed
header fails the external control. This remains a public-consumer acceptance
receipt; it does not qualify runtime routing or synthesis.

The routed first slice carries a versioned profile-one frame contract at every
edge. Its 32-byte little-endian encoding is decoded and compared at the runtime
consumer boundary before payload consumption. The existing `SpectralError`
values retain their explicit telemetry ordinals, with `InvalidContract` appended
at ordinal 20. Mutating either the decoded contract or its canonical bytes fails
closed with `IdentityMismatch`; malformed wire values fail with
`InvalidContract`. Spectral frame edges reject sparse automation and dense
audio-rate modulation. `RealMaskV1` is the only admitted mask stage; a
modulated-mask or frame-automation variant is intentionally outside this slice.
The routed controls cover serial/partition-invariant rendering, canonical
roundtrip, runtime mismatch, encoded-boundary mutation, and planted automation
refusals. These controls do not qualify granular modulation, callback timing, or
the complete A3 workflow.

This slice does not change Processor persistence or callback I/O. It does not
implement or qualify resynthesis, EOF tail audio, analyzed-asset schemas,
morph/modulation, granular fields or a complete A3 external spectral-morph
workflow. Those remain open.
