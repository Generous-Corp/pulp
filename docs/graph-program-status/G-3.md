# G-3 authored graph identity and prepared export

Status: **PARTIAL / focused D4 lane complete; broader G-3 closure pending**

The admitted D4 slice adds a public value-owned prepared-description record for
the closed serial I/O + Gain profile. `PreparedTopologyEdit::bind_authored_identity`
requires an owned canonical semantic payload and explicit node, channel, and
interface bindings. It rejects unsupported node families, non-stereo shapes,
duplicate or incomplete bindings, channel swaps, and unbound exports with typed
refusals. A committed `ExecutionSnapshot` exports only its current immutable
generation, preserving the serial snapshot identity, block bound, gain bit
patterns, authored schedule, edges, actual serial routing assignment facts (slot/input mode/delay/in-place/latency), and a canonical byte encoding plus SHA-256.

The focused positive and negative controls are registered in
`test/test_prepared_description.cpp`; the installed public-SDK consumer is in
`examples/g3-d4-prepared-export-consumer`. The current focused governed
Release receipt is fourteen of fourteen D4 tests passing, including the real stereo
input -> two Gain -> output prepare/commit/export path, parsed node/gain/edge
interface correspondence, exact final input modes, actual-plan node facts,
unbound/swapped-channel/event-lane/unknown-field refusals, detached empty export,
retired-snapshot and selection-ABA refusals, host-limit refusal, and the
independent host-input alias width/overlap/restoration oracle, and explicit
external-input/external-output access records. Canonical detached bytes order
logical node and edge records independently of the in-memory authoring vector,
and the lifetime oracle keeps an input-produced value live through its last
reader. Preparation also rechecks every compiled node kind, port shape, gain
bit pattern, and audio edge tuple against the bound candidate before publishing
a receipt. The semantic profile remains the
D1/D2 identity profile, valid non-stereo payloads reach the explicit D4 profile
refusal, and exported edge/input/buffer records retain authored channel names
and the adopted execution generation. Commit allocation failure now returns a
typed transactional refusal. The focused governed Release target build
completed and git diff --check is clean. `confirm_failure.sh`
confirmed that replacing authored channel lookup with numeric positions fails
the stereo export test; the source was restored and all three phases rebuilt.
Earlier receipts also confirmed that removing the external-output record guard
fails the stereo consumer test and that removing the non-audio-lane guard fails
its negative control. The current checkpoint additionally decodes JSON string
escapes before duplicate-key comparison, rejects malformed UTF-8 and unpaired
surrogates, exercises a real valid stereo channel-swap refusal, and verifies
that a failed prepared commit preserves the prior owner receipt.

The independent exact-plan/schedule/lifetime oracle now covers the published
chain. The export records both the bound snapshot token and exact serial pool
object identity, and rejects same-capacity or wrong-pool substitutions. Selection
generation increments saturate, and preparation/export refuse an exhausted token
instead of permitting an ABA. `confirm_failure.sh` confirmed that removing the
selection-generation refusal fails the D4 ABA control, with baseline, broken, and
restored rebuild evidence. A fresh installed SDK prefix configured, built, and ran
the standalone consumer (`ctest`: 1/1). Runtime limits remain captured from the
planner's current default limit set rather than an exported per-snapshot limit

The exact-head repository gates were rerun after the D4 provenance changes; their
current result and any unavailable lanes are recorded with the delivery receipt.
