# G-3 authored graph identity and prepared export

Status: **PARTIAL / D4 implementation in progress**

The admitted D4 slice adds a public value-owned prepared-description record for
the closed serial I/O + Gain profile. `PreparedTopologyEdit::bind_authored_identity`
requires an owned canonical semantic payload and explicit node, channel, and
interface bindings. It rejects unsupported node families, non-stereo shapes,
duplicate or incomplete bindings, channel swaps, and unbound exports with typed
refusals. A committed `ExecutionSnapshot` exports only its current immutable
generation, preserving the serial snapshot identity, block bound, gain bit
patterns, authored schedule, edges, actual serial routing assignment facts (slot/input mode/delay/in-place/latency), and a canonical byte encoding plus SHA-256.

The focused positive and negative controls are registered in
`test/test_prepared_description.cpp`; the installed public-SDK consumer is in
`examples/g3-d4-prepared-export-consumer`. The current focused governed
Release receipt is eleven of eleven D4 tests passing, including the real stereo
input -> two Gain -> output prepare/commit/export path, parsed node/gain/edge
interface correspondence, exact final input modes, actual-plan node facts,
unbound/swapped-channel/unknown-field refusals, detached empty export,
retired-snapshot and selection-ABA refusals, host-limit refusal, and the
independent host-input alias width/overlap/restoration oracle. The full governed
Release build completed and git diff --check is clean.

The independent exact-plan oracle, production snapshot/pool substitution and
selection/limit mutation controls, and cross-platform installed-consumer
receipts remain required before this slice can be called complete. The current
pool provenance is an owner-paired snapshot token; it is not yet a separately
observed allocator binding receipt. Runtime selection setters remain shared
lead-owned and currently use unlocked, wrapping generation updates; the D4
export cannot claim race-safe selection invalidation until that exact patch is
landed. Runtime limits are also captured from the planner's current default
limit set rather than an exported per-snapshot limit receipt.

This work does not claim D3/D4 whole-graph completion, hosted identity,
resolved-plan hashing, realtime safety, portability, undo, or G-3 closure.
