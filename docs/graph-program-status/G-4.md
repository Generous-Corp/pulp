# G-4: Subgraphs and macros

Status: **bounded first slice** (Wave 3)

This slice adds a declarative `SubgraphTemplate` for built-in Input, Output, and
Gain nodes. A template declares named exposed ports, parameter paths, and
feed-forward edges. `instantiate_subgraph` expands an instance into the existing
`SignalGraph` authoring plan; it does not add a second scheduler or runtime.

Each expansion receives an explicit instance identity and index. The returned
`SubgraphInstance` owns the instance-local node and port handles and can save or
restore declared parameter state. State restore checks template identity,
instance identity, and instance index before applying values. Failed edge,
node, port, or parameter validation returns a `GraphResult` whose rule is
prefixed `subgraph boundary:` and rolls back nodes created by the expansion.

The current boundary is intentional: plugin, custom-node, event, polyphony, and
nested-subgraph declarations remain future slices. This API establishes the
stable identity and diagnostics seam required before those capabilities are
added. Focused coverage is in `pulp-test-signal-graph-subgraph`.
