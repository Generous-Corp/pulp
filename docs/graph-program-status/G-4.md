# G-4: Subgraphs and macros

Status: **bounded first slice; exposed-port composition added, awaiting exact-head review** (Wave 3)

This slice adds a declarative `SubgraphTemplate` for built-in Input, Output, and
Gain nodes. A template declares named exposed ports, parameter paths, and
feed-forward edges. `instantiate_subgraph` expands an instance into the existing
`SignalGraph` authoring plan; it does not add a second scheduler or runtime.

Nested macros are now supported as a bounded extension. A child template is
value-owned by `SubgraphChildSpec`, recursively flattened into the same plan,
and addressed by a deterministic `child.port` / `child.parameter` namespace.
Child identity and instance index are retained in `SubgraphState`; a mismatched
child identity, index, duplicate key, cycle, or depth overflow is rejected at
the subgraph boundary before a graph is published. Parent declarations can
promote child ports and connect them to local built-in endpoints without
inspecting runtime node IDs.

Each expansion receives an explicit instance identity and index. The returned
`SubgraphInstance` owns the instance-local node and port handles and can save or
restore declared parameter state. State restore checks template identity,
instance identity, and instance index before applying values. Failed edge,
node, port, or parameter validation returns a `GraphResult` whose rule is
prefixed `subgraph boundary:` and rolls back nodes created by the expansion.
Parameter targets are checked against the template before graph mutation: only
Gain nodes are accepted. Input and Output targets return a boundary error without
changing existing nodes, connections, or the next allocated node ID. Regression
coverage includes both rejected node types and successful Gain default/restore.

The current boundary is intentional: plugin, custom-node, event, and polyphony
children remain future slices. This API establishes deterministic nested
identity and diagnostics for built-in control-thread templates only. Focused
coverage is in `pulp-test-signal-graph-subgraph`.

Repair validation (2026-11-03): the governed Release build passes all 12 focused
cases (88 assertions). `confirm_failure.sh` verifies the suite passes with target
prevalidation, fails when that check is disabled, and passes after restoration,
with the changed source recompiled in each phase. Full CI remains required; the
local gate host refuses heavy source-selftest and diff-coverage lanes by policy.

Identity follow-up (2026-11-04): `pulp/host/voice_identity.hpp` adds a value-only
G-4 v1 canonical key for template namespace/name/revision, bank schema, slot,
path, and optional exposed port/parameter targets. It NFC-normalizes and rejects
control characters, embedded NUL, slash-ambiguous segments, unsupported port
tags, and slot ordinals outside the eight-slot A1 bank, then emits the tagged
length-delimited big-endian encoding and its portable SHA-256 digest. The API
contains no runtime node IDs, allocator indexes, epochs, or note generations;
it therefore establishes the persistence identity seam without claiming graph
voice runtime, migration, realtime, or G-6 completion. Focused coverage is in
`pulp-test-voice-identity` (22 assertions, including planted refusals).

Composition follow-up (2026-11-05): `connect_subgraph_ports` composes two
`SubgraphInstance` values by their exposed names. It validates declaration,
output/input direction, and `PortKind` before mutation, then resolves the
instance-local aliases to the graph's canonical port names before delegating to
the ordinary `SignalGraph` connection checks. Missing, wrong-direction, and
kind-mismatch controls leave topology unchanged. The graph-spatial cookbook
now includes a source-to-sink composition and renders a 0.125 impulse through
the two gain stages; its missing and wrong-direction controls are planted
negatives. This remains control-thread graph authoring and offline render
evidence; it does not add nested templates, event routing, scheduling,
realtime, or G-3 fingerprint behavior.

Nested-macro follow-up (2026-11-06): the public installed-SDK cookbook now
expands a source-stage child through a parent template, promotes its exposed
ports, restores `inner.gain`, and rejects a planted child-identity mutation.
The focused source test also rejects cyclic and duplicate-key declarations
before graph mutation. This is control-thread flattening and offline render
evidence only; G-3 whole-graph semantic/resolved fingerprints and undo remain
PARTIAL, while G-5 event ingress/timing and realtime qualification remain
outside this slice.
