found no safe bounded implementation for the next ingress slice. The existing
host seam is a block-local MIDI/UMP mailbox: `SignalGraph::inject_midi()` accepts
`MidiBuffer` events whose `sample_offset` is already relative to the block, and
the fixed mailbox preserves a bounded prefix on overflow. The positive controls
in `test_host_signal_graph.cpp` cover MIDI ordering, UMP sample offsets, and
MPE-bearing UMP round-trip; the planted negatives cover event, SysEx, UMP, and
missing-sidecar capacity refusal.

The seam does not carry an `MpeBuffer` into a graph node. MPE is derived only
after extraction in the existing positive control. `GraphRuntimeNodeProcessContext`
has MIDI and UMP scratch but no MPE sidecar, and `ProcessorNode::process_binding`
explicitly clears `Processor::mpe_input()` and `Processor::ump_input()` around
graph dispatch. Adding host absolute-sample/time-index admission therefore
requires one contract spanning mailbox publication, routed scratch, legacy walk,
Processor binding, graph swaps, and the stale/late/overflow policy. Implementing
only one path would silently give G-6 a different event contract depending on
execution backend, so this worktree intentionally makes no runtime change.

The detailed source references, positive controls, planted negatives, and the

[`g5-host-ingress-audit-20261104.md`](../evidence/g5-host-ingress-audit-20261104.md).

transport, or graph-authored MPE voice delivery.

## MPE sidecar binding prerequisite (2026-11-05)

The reviewed bounded sidecar now follows the existing MIDI mailbox and routed
executor scratch. `SignalGraph::inject_midi(node, midi, mpe)` and the pinned
`ExecutionSnapshot` overload publish one sequence carrying both payloads. Each
routed node has fixed-capacity MPE input/output sidecars; inbound event edges
copy them in producer order, and a `ProcessorNode` receives the borrowed sidecar
together with its UMP attachment through the normal `EventBlock`. Legacy
MIDI input/output runtime state and gap-free snapshot mailbox identity retain
the sidecar alongside the MIDI/UMP payload. Sidecar copies are bounded and
mark the same incomplete/drop state as the MIDI lane.

This is plumbing only. It does not add tracker ownership or absolute-sample
conversion: existing G-5 `HostEventIngress::derive_mpe` remains the reviewed
source of block-relative MPE events, and stale/late/overflow/epoch policy stays
at that contract boundary. The sidecar is delivered to authored Processor nodes;
hosted `PluginSlot` nodes and MIDI egress remain MIDI/UMP-only until their own
per-note format contracts are admitted.
