## Consumed-data contract

The existing fixed 256-record SPSC ring, drop accounting, snapshot ownership,
mutation lock, and one selection per lane remain authoritative. No scheduler,
ring, record layout, or observation API is added.

Ordinary and sidechain audio retain the source-side pre-mixing/pre-PDC contract.
The selected channel is sampled before scratch reuse, including an aliased host
input channel. Feedback instead summarizes the persistent previous-block slot
that the destination reads, before current output overwrites it. Its timestamp
marks the receiving block on the attachment-relative sample clock. The existing
feedback executor overwrites only the active prefix on short callbacks; the
oracle explicitly retains the untouched max-block tail. This slice does not
change that execution behavior or claim feedback partition invariance.

Sparse controls retain their mapped/slewed endpoints. Dense audio-rate controls
summarize the actual per-edge values after connection PDC, range mapping, and
slew, before destination Replace/Add mixing and bounds clamping. `value` and
`value_end` are the first and last contributions, `peak` is maximum absolute
contribution, `rms` covers all contributions, and `payload_count == frames`.
These bounded summaries do not reconstruct every sample. Sparse summary fields
remain zero; event semantics remain unchanged.

Attach/detach/reprepare/topology and reset/mode lifecycle restrictions remain in
force. Reattachment creates a fresh ring and zero-based clock. Overflow drops
records without delaying processing; sequence counts successful publications,
and timestamps continue through dropped callbacks.

## Acceptance and evidence

The host tests compare a scalar feedback recurrence and sidechain channel
oracle against both rendered data and probe records over fixed and irregular
partitions. Dense tests independently compute every mapped/slewed value and
check delivered mixed/clamped parameter values separately from selected-edge
summaries. They cover attachment identity, overflow, detach, fresh clocks,
reprepare, and topology retirement.

The existing installed public consumer additionally exercises dense legacy
event and borrowed-view delivery with real three-sample PDC. Its expected
values use an independent delayed input history, and callbacks verify the
actual parameter events and dense views separately from probe records. The same
consumer checks sidechain delivery and retained feedback against scalar oracles.
