# G-8 — graph multirate domains

Status: **NO-CHANGE / evidence-gated**.

The live-main source still prepares one host sample rate and block size per
compiled graph snapshot. Processor-local resampling and oversampling remain
available, but no graph-owned rate domain, conversion edge, or mixed-rate
scheduler is admitted. This bounded audit adds no runtime or API surface.

The exact source head, positive controls, planted negatives, and Processor-local
conversion controls are recorded in the [2026-11-06 multirate audit](../evidence/advanced-graph-multirate-2026-11-06.md).

Reopen G-8 when the first concrete G-5 or G-6 workflow requires a node to run at
a different rate from its graph host. That reopening packet must name the
workflow and conversion ratio, then prove buffer and state mapping, tail and
timestamp semantics, scheduler admission, PDC, unsupported-conversion errors,
block-boundary continuity, an aliasing negative, bounded callback cost, offline
parity, and supported-platform behavior.
