# G-11: spatial, tuning, and live sampling cookbook

Status: **PARTIAL — static stereo, named format-bus, tuning, and live-sampling recipes**.

The installed-SDK consumer in `examples/graph-named-bus-cookbook` declares a
mono `Source` input, stereo `Front` main output, and optional stereo `Rear`
aux output. It selects declared layouts through the public format API and
renders through named `ProcessBuffers` in a direct host-side harness. Positive
controls cover front-only and front-plus-rear layouts; planted swapped output
names and an undeclared layout are rejected.

The installed SDK consumer in `examples/graph-spatial-cookbook` uses G-4's
public bounded Input/Output/Gain subgraph template to route one mono input to
the two channels of a stereo output. Two declared gain paths carry independent
instance-local state. Its fixture renders a known impulse, checks both channels
and every silent frame, restores state, and confirms a planted swapped edge is
rejected by the same oracle.

Both recipes are fixed channel weighting. The named-bus recipe proves the
format processor contract, not named-bus integration in SignalGraph. G-4
exposed port names are graph handles; the Output node's port indices select
host channel positions. The static tuning recipe is documented in
`examples/g11-tuning-cookbook`. The live-sampling recipe is the installed-SDK
`sample-region-allpass` consumer described in
[`g11-live-sampling-cookbook`](../guides/g11-live-sampling-cookbook.md): it
declares a bounded sample-region graph with explicit `UnitDelay` causality,
renders regular and irregular callback schedules, reloads and bakes the graph,
and checks an independent scalar oracle. A historical local run reported six
render paths and a maximum oracle error of `6.5035055230033834e-08`; planted
negatives cover changed graph contracts, tampered or untrusted signed bakes,
legacy loader admission, and a changed output sample. The exact receipt and
SDK provenance from that run are described in the prose-only historical note
[`g11-live-sampling-evidence-20261105`](../reports/g11-live-sampling-evidence-20261105.md).
Those values are historical run notes only: the receipt, executable, copied
consumer, and SDK prefix are not committed, so they are not current-head or
durable evidence. This is an installed-SDK consumer recipe for the public graph
APIs, not a claim of live recording, callback file I/O, realtime qualification,
or full spatial capability.
