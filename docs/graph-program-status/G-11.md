# G-11: spatial, tuning, and live sampling cookbook

Status: **PARTIAL — static stereo recipe only**.

The installed SDK consumer in `examples/graph-spatial-cookbook` uses G-4's
public bounded Input/Output/Gain subgraph template to route one mono input to
the two channels of a stereo output. Two declared gain paths carry independent
instance-local state. Its fixture renders a known impulse, checks both channels
and every silent frame, restores state, and confirms a planted swapped edge is
rejected by the same oracle.

This is fixed channel weighting. G-4 exposed port names do not supply named-bus
layout negotiation; the Output node's port indices select host channel
positions. Tuning and live sampling remain separate G-11 recipes. No recording
publication, callback file I/O, baked artifact, realtime, or full spatial
capability is claimed here.
