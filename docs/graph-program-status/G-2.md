# G-2 — Graph notation, save format, and CLI/MCP

Status: **implemented locally; PR pending**

The canonical `.pulpgraph` JSON notation is owned by `pulp::host::GraphSerializer`.
This slice adds `pulp graph inspect`, `pulp graph validate`, and
`pulp graph canonicalize`; all load with plugins disabled, preserving a safe,
metadata-only inspection path. The `pulp_graph` MCP tool delegates to the same
CLI surface and accepts `operation` (`inspect`, `validate`, or `canonicalize`) and
`path`.

Acceptance: deterministic serializer round-trip remains covered by
`test_graph_serializer`; CLI/MCP wiring is exercised by the corresponding build
and tool-surface checks. Canonicalize rewrites atomically only in a future slice;
callers should use it on a disposable copy for now.
