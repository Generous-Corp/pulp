# G-3 authored graph identity

Status: **PARTIAL / EVIDENCE-GATED**

Wave 3 implements the post-G-1 authored-port identity surface in
`pulp/host/graph_identity.hpp`. It validates UTF-8 scalar names, rejects NUL,
control, empty, whitespace-only, and duplicate normalized names, applies the
one-hop versioned alias rule, and computes an order-independent semantic
fingerprint. The same value-owned surface reports added/removed names and
canonical-order changes and captures a caller-applied undo record.

The implementation is control-side only. Canonical port numbers, runtime
scheduling, instance pointers, host paths, telemetry, and machine-specific
execution choices are excluded. Fingerprints return zero for invalid records;
no lossy replacement string is emitted in diagnostics. NFC composition covers
the authored combining sequences used by the conformance fixture while
preserving unknown valid scalar sequences byte-for-byte.

Executable planted controls are in `test/test_graph_identity.cpp`:

- `cutoff`, `drive`, and `mix` remain identical after reorder;
- declared `drive` → `Drive` alias resolves to authored `drive`;
- undeclared rename, duplicate names, whitespace-only name, embedded NUL,
  invalid UTF-8, and decomposed-vs-composed Unicode controls;
- value-owned undo capture and restoration.

The broader graph semantic/execution receipt packet remains evidence-gated:
plugin identity portability, floating-point canonicalization, prepared-plan
fingerprints, cross-process receipts, and runtime mutation lineage still need a
separate owner and conformance lane. This slice does not make those claims.
