## Audio display registration

`Meter`, `WaveformView`, and `SpectrumView` are provided by
`pulp::view-audio`. Applications that link the view targets directly and do
not use a Pulp format host must call `pulp::view::register_audio_widgets()` at
startup. Existing format and standalone entry points register them explicitly.

The generic `LevelDisplay`, `SeriesDisplay`, and `BinDisplay` interfaces remain
available from `pulp::view-core`; use those interfaces when writing extracted or
provider-neutral code.
