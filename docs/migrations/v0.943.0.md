## What changed

Two umbrella headers stopped including headers that most of their includers
never used:

- `<pulp/view/widgets.hpp>` no longer includes `<pulp/view/visualizers.hpp>`.
  `SpectrogramView`, `MultiMeter` and `CorrelationMeter` are no longer declared
  through `widgets.hpp`.
- `<pulp/view/view_all.hpp>` no longer includes
  `<pulp/view/waveform_gpu_primitives.hpp>`,
  `<pulp/view/waveform_gpu_render_controller.hpp>` or
  `<pulp/view/waveform_headless_render_backend.hpp>`.

No class, function or link target changed. Only the transitive includes are
gone.

## Who is affected

Code that uses `SpectrogramView`, `MultiMeter`, `CorrelationMeter` or a
waveform GPU type while including only `widgets.hpp` or `view_all.hpp`. Such
code now fails to compile with an undeclared identifier for that type.

## Migration steps

Include the header that declares the type you use:

```cpp
#include <pulp/view/visualizers.hpp>                    // SpectrogramView, MultiMeter, CorrelationMeter
#include <pulp/view/waveform_gpu_primitives.hpp>        // waveform GPU primitives
#include <pulp/view/waveform_gpu_render_controller.hpp> // waveform GPU render controller
#include <pulp/view/waveform_headless_render_backend.hpp>
```

The headers and their link target (`pulp::view`) are unchanged, so no CMake
edit is needed.
