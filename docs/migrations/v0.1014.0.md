## What changed

These are renderer changes, so they affect every Pulp UI, not only imported
designs. No API changed.

- **CSS generic families resolve to platform faces.** On macOS, `sans-serif`
  resolves to Helvetica, `serif` to Times, `monospace` to Menlo, and
  `system-ui` / `BlinkMacSystemFont` to the system UI font (SF), matching
  Chromium's defaults. Previously these names matched no platform face and fell
  through to the next fallback, often a bundled face such as Jost. A quoted
  generic (`"serif"`) is a literal family name, as in CSS. Other platforms keep
  their existing resolution.
- **Optical size and tracking.** A variable font with an `opsz` axis renders at
  an optical size equal to its CSS pixel size (`font-optical-sizing: auto`), and
  a face with an AAT `trak` table (the macOS system font) applies its
  size-dependent tracking, so SF text matches Chromium's widths.
- **Baselines.** `fill_text` now lands its baseline exactly on the requested
  `y` (previously up to half a pixel off, depending on the face's ascent
  rounding), and letter-spaced runs start at `x` with the spacing after each
  glyph.
- **Right-to-left canvas text** measures and draws in the canvas's direction;
  RTL text through that path previously drew nothing.
- **Borders.** `outset`, `inset`, `groove`, `ridge`, and `double` paint with
  Chromium's per-side shading and band widths instead of a solid line, and
  rounded borders use CSS radius normalisation for both the background and
  the border.

## Who is affected

UIs that name a CSS generic family (`sans-serif`, `system-ui`, `monospace`),
draw letter-spaced or right-to-left canvas text, or use 3D or double border
styles. Text set in a named family (for example the default theme's `Inter`)
is unaffected by the generic-family change: the stock `pulp-ui-preview` widget
screenshot renders byte-identically before and after. The component inspector
overlay, which requests `monospace` throughout and sizes its caret from the
width of "0", now renders in Menlo as written; before, `monospace` fell through
to a proportional face. Expect some labels to shift by up to one device pixel
vertically and some system-font text to change width.

## Migration steps

To keep a specific face, name it explicitly instead of a generic family (for
example `font-family: "Jost"`). Screenshot goldens that include generic-family
or system-font text, letter-spaced text, or 3D borders need regenerating.
