## What changed

`pulp_add_plugin()` and `pulp_add_plugin_bundle()` used to ignore any argument
they did not recognise: a misspelled keyword (`PLUGIN_NAMEE`), a keyword newer
than the SDK in use, a stray value before the first keyword, or a `FORMATS`
value nothing handles (`clap`, `VST`). The plug-in configured, but without the
setting you wrote, or without that format. These are now configuration errors:

```
pulp_add_plugin(MyPlugin): unknown argument(s): PLUGIN_NAMEE, My Plugin. ...
pulp_add_plugin(MyPlugin): unknown format(s): clap. Known formats: VST3, CLAP, AU, LV2, AAX, AUv3, Standalone.
```

`PRODUCES_MIDI` keeps its existing warning (it is metadata on the processor
descriptor, not a packaging flag). Calls that only use documented keywords and
format names are unchanged.

## Migration steps

1. Configure your project. If it now stops with `unknown argument(s)` or
   `unknown format(s)`, the named argument was being ignored before.
2. Fix the spelling, or remove the argument. Format names are case-sensitive:
   `VST3`, `CLAP`, `AU`, `LV2`, `AAX`, `AUv3`, `Standalone`.
3. If the keyword is valid in a newer SDK than the one your project pins
   (for example `NO_EDITOR`), update the pin (`pulp project pin`) rather than
   deleting the keyword.
