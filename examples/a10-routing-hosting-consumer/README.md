# A10 routing and hosting consumer

This fixture is an external installed-SDK consumer. It exercises the public
`Pulp::host` surface for a caller-owned hosted slot: named sidechain route
registration, parameter automation route registration, prepared latency
introspection, and transactional topology preparation. It also checks planted
refusals for sidechain-to-audio and an unknown parameter. The slot is an in-process deterministic test
double; this is host wiring evidence and does not claim arbitrary third-party
plugin containment, callback safety, recovery, or cross-platform isolation.
