Forge Modular (beta)

Forge Modular generates VCV Rack patches and modules from a description.
Type what you want, and it builds it.

WHAT GETS INSTALLED

  Forge Modular.app          in your Applications folder
  The Forge Modular modules  so VCV Rack can use them
  AU, VST3 and CLAP          only if you tick them

Forge Modular itself is required, because the Rack modules and the
uninstaller live inside it. The plug-in formats are optional.

ABOUT BUILDING MODULES

Generating a patch works straight away. It needs nothing else.

Generating a new module compiles real code on your Mac, so the first time
you do it Forge Modular will offer to download the VCV Rack SDK. That SDK
belongs to VCV and is licensed under the GPLv3. We do not ship a copy of
it; your Mac downloads it from vcvrack.com when you say yes. If you never
build a module, it is never downloaded.

Building modules also needs Apple's Xcode Command Line Tools. If they are
missing, Forge Modular will tell you and give you the one command that
installs them.

A module you build links the Rack SDK, so it inherits the GPLv3. That is
fine for your own use. If you ever share one, its licence follows from
that.

REMOVING IT

An uninstaller ships inside the app. It removes the app, the plug-ins, the
Rack modules and the downloaded SDK, and it keeps the patches you have
made unless you ask it not to.
